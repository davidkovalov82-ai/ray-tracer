## Краткие разборы небольших тем

### 1. Настройки CMake для стандарта C++
**Вопрос:** Что делают строки `set(CMAKE_CXX_STANDARD_REQUIRED ON)` и `set(CMAKE_CXX_EXTENSIONS OFF)`?

**Смысл:** CMake управляет компилятором. По умолчанию компилятор может использовать старую версию C++ или добавлять свои нестандартные фишки (расширения). 

**Как работает:**
- `CMAKE_CXX_STANDARD_REQUIRED ON` — говорит: "Если у пользователя слишком старый компилятор, который не поддерживает запрошенный стандарт (у нас C++17), выдай ошибку и остановись". Без этого CMake мог бы молча собрать проект под старый стандарт, и часть функций сломалась бы.
- `CMAKE_CXX_EXTENSIONS OFF` — запрещает компилятору использовать "свои личные" дополнения к языку C++ (например, специфичные для GCC). Это гарантирует, что ваш код соберется на *любом* компиляторе (на Mac, Windows, Linux), так как использует только строгий мировой стандарт.

**Вывод:** Эти строки делают ваш проект надежным и переносимым на другие компьютеры.

**Самопроверка:** Если удалить `CMAKE_CXX_EXTENSIONS OFF`, перестанет ли компилироваться код прямо сейчас? (Ответ: скорее всего нет, но в будущем вы могли бы случайно использовать нестандартную функцию, и код перестал бы работать у друга на Windows).

### 2. Защита заголовочных файлов
**Вопрос:** Что значит `#pragma once` в начале `.h` файлов?

**Смысл:** Это команда компилятору: "Включай этот файл в код только один раз".

**Как работает:** Когда в `main.cpp` вы пишете `#include "color.h"`, а потом подключаете `ppm.h`, который тоже внутри делает `#include "color.h"`, компилятор видит содержимое `color.h` дважды. Из-за этого может возникнуть ошибка "структура Color переопределена". `#pragma once` предотвращает это дублирование.

**Типичная ошибка:** Забыть написать `#pragma once` в новом `.h` файле и получить непонятную ошибку `redefinition of struct ...`.

**Самопроверка:** В каких файлах нужно писать `#pragma once`: в `.cpp` или в `.h`? (Ответ: только в `.h`).

### 3. Создание папок через код
**Вопрос:** Что делает `std::filesystem::create_directories("images/ppm");`?

**Смысл:** Это команда стандартной библиотеки C++17 для безопасного создания папок на жестком диске. 

**Как работает:** Команда просит операционную систему создать папку `images`, а внутри неё папку `ppm`. Главный плюс этой функции: если папка *уже существует*, программа просто пойдет дальше без ошибок. 

**Вывод:** Это автоматизирует подготовку: кто бы ни скачал ваш код, папки создадутся сами при запуске.
